# @softwhere-uz/expo-yandex-mapkit

This is the **official scoped alias** of [`expo-yandex-mapkit`](https://www.npmjs.com/package/expo-yandex-mapkit), maintained by [softwhere-uz](https://github.com/softwhere-uz).

**Installing the unscoped package directly is recommended:**

```sh
npx expo install expo-yandex-mapkit
```

Both names track the same code. This package contains no native code of its own — it simply depends on `expo-yandex-mapkit` and re-exports it (including the config plugin), so Expo autolinking always resolves to the single real module. It exists so that the scoped name verifiably belongs to the same maintainers as the unscoped one.

For documentation, issues, and source, see the main repository: <https://github.com/softwhere-uz/expo-yandex-mapkit>.
